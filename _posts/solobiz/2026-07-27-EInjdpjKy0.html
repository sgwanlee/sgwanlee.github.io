Claude Code로 Google Ads 전과정 자동화 — $730,000를 만든 4가지 전략

출처: Jono Catliff — Claude Code Google Ads: Automate Everything ($730K Earned) · 러닝타임 1시간 8분

"이 영상은 지난 7년간의 Google Ads 지식을 하나의 영상으로 압축한 것이다. 게이트키핑 없이, Cloud Code로 광고 계정 전체를 자동화하는 법을 공개한다." — Jono

1. 오프닝 — $177K 지출로 $730K 벌기 (00:00~00:50)

발표자 Jono Catliff가 실제 광고 계정을 공개한다. 이전에 매각한 웨딩 DJ 비즈니스로 $177,000를 써서 $730,000의 매출을 만들었고, 전환율은 약 20% (상위 1%) 수준. 이 영상 하나로 이 모든 노하우를 압축해서 전달한다는 것이 목표.

2. Google이 시키는 대로 하지 마라 (02:28~04:00)

Google이 밀어주는 것들은 당신이 더 많이 쓰게 만들기 위한 것이지 당신의 수익을 위한 것이 아니다.

  • Optimization Score / Recommendations: 대부분 지출 늘리라는 유도. 무시.
  • Google 계정 매니저의 주간 콜: 그들의 보너스는 당신의 지출 증가에 연동돼 있음.
  • 클릭·CTR·전환수 같은 지표: 유일하게 중요한 건 실제로 번 돈. 트래킹을 세팅해 어느 채널이 진짜 매출을 만드는지 봐라.

3. 키워드 매치 타입 — Phrase가 정답 (05:00~06:25)

다트판 비유. 가운데가 이상적이지만 볼륨이 부족하므로 조금 범위를 넓혀야 한다.

  • Broad Match ❌: Google이 "의미가 비슷한" 키워드까지 끌어옴. plumber salary, plumber memes 같은 곳에도 돈 태워짐. 예산 소각.
  • Phrase Match ✅ (승자): 검색어에 해당 구문이 포함되면 노출. "24/7 emergency plumber toronto downtown" 등 수천 가지 표현을 잡을 수 있음.
  • Exact Match: 정확히 그 구문일 때만. 안전하지만 볼륨이 너무 좁음.

4. Keyword Planner로 승자 키워드 찾기 (06:25~09:00)

Google 무료 도구인 Keyword Planner를 쓴다. 반드시 도시 단위로 지역을 좁혀야 관련 없는 트래픽에 돈이 새지 않는다.

돈이 되는 키워드 패턴:

  • "emergency + 서비스" (긴급성 신호)
  • "서비스 + near me"
  • "서비스 + 도시명"
  • "24/7 + 서비스"

피할 키워드: 경쟁사 이름 (Rotorooter 등 — 이미 그 회사를 검색하는 사람), 채용/교육/DIY 관련, 자재/부품 검색.

매트릭스 전략: "서비스 × 도시" 조합으로 랜딩페이지를 도시별로 대량 생성. 단 소도시는 볼륨이 안 나오니 확인 필요.

5. $700K 핵심 전략 — Single Keyword Ad Group (SKAG) (09:00~11:10)

이 영상의 핵심 전략. 검색어 = 광고 문구 = 랜딩페이지 헤드라인이 완벽하게 일치해야 한다.

검색: "plumber services toronto" →
광고: "Plumber Services Toronto" (아니면 최소 "Plumber Toronto") →
랜딩: "Trusted Toronto Plumbers"

일반화된 광고가 일반화된 랜딩페이지, 일반화된 이메일, 일반화된 세일즈콜로 이어지면 전환율이 처참하다. SKAG는 하나의 광고그룹 = 하나의 검색어 = 하나의 광고 = 하나의 랜딩페이지 구조.

6. Claude Code ↔ Google Ads 연결 세팅 (11:10~18:20)

한 번만 세팅하면 다시는 할 필요 없음. 대략적인 순서:

  1. VS Code 설치 → Claude 확장 설치. 프로젝트 폴더 하나 만들기.
  2. Google Ads Manager 계정 생성 → 서브 계정으로 실제 광고 계정 연결.
  3. Admin → API Center에서 Developer Token 발급 (기본 2,880 requests/day).
  4. Google Cloud Console에서 새 프로젝트 생성 → Google Ads API 활성화 → OAuth 동의 화면 세팅 → Test User에 본인 이메일 추가.
  5. Credentials에서 OAuth Desktop Application 클라이언트 생성 → JSON 다운로드 → credentials.json으로 Cloud Code 폴더에 저장.
  6. Claude에게 "이 파일 읽고 Google 인증해줘" 요청 → 브라우저 OAuth 확인 → 연결 완료.

7. Google Ads 3계층 구조 이해 (18:20~19:57)

  • Campaign (캠페인): 서비스별로 묶음. 예산·요일·시간·지역 등 상위 설정.
  • Ad Group (광고그룹): SKAG 전략 → 검색어 하나당 광고그룹 하나.
  • Ads (광고): Split test를 위해 수십~수백 개 변형을 돌려서 outlier winner를 찾아야 함. 하나만 돌리면 결과가 안 좋을 확률이 크다.

8. Claude로 캠페인 자동 생성 — 9가지 기본 스위치 (22:50~28:30)

Claude에게 campaigns.md + 도메인만 주면 알아서 세팅한다. 반드시 이 9가지 기본값을 지켜야 함:

  1. Campaign Type: Search Network only (Performance Max/Display/Demand Gen은 서비스업엔 쓰레기 트래픽)
  2. Bidding: Max Conversions → 이후 tROAS로 전환
  3. Schedule: 24/7 or 업무시간만 (야간은 저렴하지만 컨택률↓)
  4. Locations: 도심 반경 50km, Presence only (Interest는 인도·중국까지 잡힘)
  5. Excluded Locations: 자국 제외 나머지 국가 전부 (VPN·봇 클릭 차단)
  6. Devices: 모든 기기
  7. Audience Segments: Skip (콜드 캠페인은 세그멘테이션하면 돈 새는 것)
  8. Auto Recommendations: 모두 OFF
  9. Ad Rotation: Optimize (default)

9. 광고 단가를 낮추는 3가지 방법 (29:30~33:00)

  1. Smart Bidding 웜업: Google이 새 계정을 이해할 시간을 줌.
  2. 나쁜 검색어 랭킹 제거: SKAG 구조가 이걸 기본으로 해결. 그래도 걸리는 나쁜 검색어는 즉시 negative로 이동.
  3. Quality Score 올리기: Expected CTR + Ad Relevance + Landing Page Relevance 3요소. 이게 오르면 클릭당 비용이 내려간다. SKAG는 이 3요소를 자동으로 최대화하는 구조.

최종적으로 뭘 최적화해야 하나: 클릭도 리드도 아니고 매출/이익. 리드가 스팸일 수 있고 저품질일 수 있으므로 결국 페잉 커스터머 데이터를 Google에 다시 업로드해서 tROAS 캠페인으로 전환해야 함.

10. Claude로 벌크 광고 생성 (33:00~37:20)

수동으로 200개 광고 만들면 8~16시간. Claude는 몇 분. 두 개의 참고 파일이 필요:

  • anatomy-of-a-good-ad.md
  • add-assets-best-practices.md

Claude가 자동 생성하는 요소: 15개 헤드라인, 여러 개의 디스크립션, Callouts (24/7 emergency service, no callout fee, licensed and insured 등), Structured Snippets (제공 서비스 목록), Site Links (다른 페이지로의 링크). 이 확장 요소들이 광고의 디지털 부동산 점유율을 넓혀서 클릭률을 올린다.

11. Pinned Headlines — 검색어를 무조건 1번에 (38:00~40:00)

Google은 15개 헤드라인을 자동 로테이션하는데, 1번 자리는 반드시 pin하고 "검색어와 동일한 root 키워드"를 넣어야 한다. 그 뒤 자리들만 회전시켜 최적을 찾아야 함.

사람들이 광고를 스킵하는 가장 큰 이유는 "이게 뭐지? 이 회사가 뭘 하는지 모르겠다"는 순간. Root 검색어를 첫 헤드라인에 고정하면 스킵률이 급감한다.

12. Negative Keywords — 유니버설 리스트 (40:00~43:00)

서비스업이라면 무조건 제외해야 하는 카테고리:

  • Job seekers (plumber school, plumber apprenticeship)
  • DIY (do-it-yourself, how to)
  • Training/certification (course, class, exam)
  • Free/coupon (무료, 할인 검색자)
  • Definition/wikipedia 등 정보성 검색
  • Customer support, existing customers (기존 고객 지원 검색)

영상 제작자가 이 리스트를 universal-negative-keywords.md 파일로 배포. Claude에게 주면 모든 캠페인에 공유되는 부정 키워드 리스트로 자동 세팅.

13. Claude + Dribbble로 랜딩페이지 자동 생성 (43:00~45:20)

  1. Next.js 프레임워크 사용 (커스텀 코드용 WordPress로 비유).
  2. Dribbble에서 "plumbing website" 등으로 검색해 마음에 드는 디자인 스크린샷 저장.
  3. Claude에게 이미지 첨부 + 프롬프트 → 디자인을 거의 그대로 복제해서 SKAG 검색어에 맞는 랜딩페이지 생성.
  4. 로컬호스트에서 프리뷰. 아직 배포 전.

수동으로 하면 한 달 걸릴 작업이 몇 분으로 압축된다.

14. High-Converting 랜딩페이지 원칙 + 60초 룰 (45:20~48:00)

20% 전환율을 만든 랜딩페이지 원칙:

  • Split testing이 가장 위 (SS 티어): 내 의견도, 친구 의견도 다 틀릴 수 있다. 데이터만이 진실.
  • Video testimonials: Social proof가 최고의 신뢰 신호.
  • 랜딩페이지에 직접 폼 배치: 2차 페이지로 보내면 전환율 급락.
  • Founder video: "서비스"를 파는 게 아니라 "나 자신"을 판다. 사람들은 좋아하고 신뢰하는 사람에게 산다.
  • ⚡ Speed to Lead 60초 룰: 평균 비즈니스는 리드에게 답하는 데 48시간 걸린다. 60초 안에 전화하면 매출이 4배가 된다. 광고비 더 안 쓰고, 마케팅 더 안 해도, 그냥 빨리 전화만 해도 4배.

15. Remarketing — Google Tag + Warm Audience (48:00~54:00)

Cold audience (당신을 처음 보는 사람)는 전환율이 낮다. Warm audience (사이트를 이미 방문했던 사람)는 전환율이 훨씬 높다.

Google Tag를 랜딩페이지에 심으면 방문자가 자동으로 리마케팅 오디언스에 축적됨. 이후 그 사람들에게만 다시 search 광고를 노출 (RLSA — Remarketing Lists for Search Ads). Display 리마케팅은 hit and miss라 선택적.

세팅 검증: Google Tag Assistant에 URL 넣고 submission event 테스트. Playwright MCP를 붙이면 Claude가 이 테스트도 자동으로 해줌.

16. ROAS 대시보드 — 매주 월요일에 볼 것 (54:00~56:00)

Claude Code가 만들어주는 ROAS 대시보드. 매주 월요일에 열어서 확인하고 액션.

  • 캠페인별 Spend / Revenue / ROAS 한눈에
  • Claude의 자동 추천: 정지할 캠페인, 스케일업할 캠페인, 추가할 negative keyword, QS 낮은 키워드 등
  • "Send to Claude" 버튼으로 추천을 큐에 넣고 Claude가 실제 계정에 반영

"광고 대행사가 $5,000 청구하는 일을 월 $20~100짜리 Claude가 대신한다"는 게 화자의 주장.

17. ROAS 트래킹 파이프라인 — 5단계 (56:00~1:00:00)

실제 매출까지 추적하는 5단계 파이프라인:

  1. URL 파라미터: Google Ads가 클릭할 때 ?term=wedding+dj&campaign=weddings-toronto&gclid=...&source=google&medium=cpc 형태로 정보를 URL에 붙임.
  2. Hidden Form Fields: 랜딩페이지 폼에 숨겨진 필드가 URL 파라미터를 캡처.
  3. CRM 저장: 폼 제출 시 CRM에 리드 + gclid + campaign + keyword 함께 저장.
  4. 결제 트리거: Sarah가 인보이스 결제하면 워크플로우가 CRM 데이터를 대시보드로 업데이트.
  5. Offline Conversion Upload: 이 데이터를 CSV로 Google Ads에 다시 업로드 → Google이 실제 페잉 커스터머와 유사한 사람을 더 잘 찾아줌.

18. Claude로 Negative Search Terms 자동 감사 (1:00:00~1:03:00)

SKAG를 잘 세팅해도 매칭이 잘못된 검색어가 나온다. Claude에게 find-and-add-negatives.md 프롬프트 실행 시키면 리포트 생성:

예: "DJ hiring" → Jono는 "DJ를 고용하려는 사람"으로 오해했는데, Claude가 검색 결과 조사 → 실제로는 "DJ 직업을 구하는 사람"의 검색어. 이런 인사이트는 몇 년을 돌려도 사람은 안 잡힌다.

승인만 하면 Claude가 negative keyword 리스트에 자동 추가.

19. GitHub + Vercel로 사이트 배포 (1:03:00~1:05:30)

2단계로 무료 배포:

  1. GitHub: Private repository 생성 → Claude에게 "landing-pages 폴더를 이 repo에 업로드해줘" 요청.
  2. Vercel: Vercel에 GitHub 계정 연결 → Import project → 프리셋 Next.js → Deploy.

배포된 도메인을 Google Ads 캠페인의 Final URL로 교체하면 완성.

20. Claude Skills로 반복 작업 10배 가속 (1:05:30~1:07:00)

매번 컨텍스트를 다시 주기 귀찮다면 Skill로 감싸라. 한 번 만들어두면 새 대화에서 /generate-ads처럼 슬래시 커맨드로 호출 가능.

"Please generate another 5 ads in the Toronto plumbing ad group" 한 줄이면 이전에 세팅한 anatomy 파일·SKAG 원칙·pinned headline 규칙까지 모두 자동 적용.

한줄 요약 & 실전 체크리스트

한줄 요약: Google Ads의 승리 방정식은 SKAG(검색어=광고=랜딩) × 부정 키워드 관리 × ROAS 트래킹 × 60초 콜백이며, 이 전 과정을 Claude Code로 자동화하면 광고 대행사 없이 혼자서 계정 전체를 운영할 수 있다.

  • ☑ Broad match 금지, Phrase match 사용
  • ☑ SKAG 구조: 광고그룹 하나당 검색어 하나 하나당 광고 하나 하나당 랜딩페이지 하나
  • ☑ Presence only 위치 타깃, 자국 외 국가 excluded로 봇 차단
  • ☑ 15개 헤드라인 중 첫 번째는 반드시 root 키워드로 pin
  • ☑ Universal negative keyword 리스트 (job/DIY/course/coupon)를 모든 캠페인 공유
  • ☑ Google Tag 설치 → 방문자 리마케팅 오디언스 축적 → RLSA로 재타깃
  • ☑ 리드 유입 후 60초 내 콜백 — 매출 4배 지렛대
  • ☑ URL parameter + Hidden form field + CRM + Offline conversion upload로 실매출을 Google에 다시 학습시키기
  • ☑ Claude Skill (/generate-ads, /audit-account 등)로 반복 작업 캡슐화
  • ☑ Performance Max / Display / Demand Gen은 서비스업엔 예산 소각. Search만.
