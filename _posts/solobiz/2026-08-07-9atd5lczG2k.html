월 $800,000 앱을 코드 한 줄 없이 클론하는 법 — Claude Code로 만든 Recipe 앱 풀 워크플로우

이 강의의 화자는 월 $800,000 매출의 실제 앱(ResuMe — 웹/YouTube 레시피 스크래핑 + AI 정리 앱)을 코드 한 줄도 안 쓰고 Claude Code + Claude Design + React Native + Expo Go 조합으로 완전히 클론한다. 이 리포트는 그 워크플로우 전체와, 이런 앱을 지어도 돈을 벌 수 없는 진짜 이유인 마케팅 · UGC 스케일 원리를 정리한다. 곱씹을 만한 이 강의의 진짜 통찰은: 앱 빌드가 아니라 UGC 콘텐츠 스케일업이 새 인디해커의 진짜 승부처라는 것.

이 리포트가 답하는 질문
- ResuMe가 월 $800K를 버는 원리 — 스티키니스 · 사용자 데이터 락인?
- 앱 하나로 $9.6M+ 엑싯이 가능한 SaaS 인수 배수(2~4x annual profit)의 실측?
- 왜 Cookpad 일본 특화 앱이 월 $900K(오히려 ResuMe보다 많이)를 버는가? 니치 특화의 힘?
- Claude Design + Claude Code + React Native + Expo Go 조합의 실전 셋업?
- 어떻게 30분 만에 이미지 스캔 · YouTube 링크 파싱 · Make Healthier AI 기능을 구현하는가?
- Supabase + RevenueCat + Apple Developer Account $99/년의 프로덕션 스택?
- UGC 콘텐츠 3가지 전략: 자체 계정 · 인간 UGC 크리에이터 · AI UGC(Arcads · HeyGen)?
- Vibe coded 앱이 App Store에서 거부되는 이유와 18개 체크리스트?

1. 인트로 — $800K/월 앱을 클론한다는 도발 (0:00~2:00)

[[SECTION1_IMG]]

화자의 오프닝은 강한 명제다. "월 $800,000을 버는 앱을 발견했고, 이 앱 전체를 코드 한 줄도 안 쓰고 만들었다."

ResuMe (원본 앱)
- 기능: 웹사이트나 YouTube 영상에서 레시피 링크만 붙여넣으면 AI가 정보 추출 → 깨끗한 레시피 카드로 저장
- 물리적 종이 레시피도 사진 촬영으로 인식
- AI 칼로리 계산 자동
- 매출: 월 $800,000

화자의 강조: 이 강의의 목적은 이 앱을 복제해서 $800K를 벌라는 게 아니다. 그 대신:

  1. 2026년에 모바일 앱을 만드는 게 얼마나 가능한지 보여주기
  2. 이런 앱을 만드는 정확한 워크플로우
  3. 마케팅 방법

2. 이 앱이 매력적인 이유 — 스티키니스와 엑싯 잠재력 (2:00~3:00)

[[SECTION2_IMG]]

이 앱이 매력적인 2가지 이유
① Recurring Revenue: 월 $800K가 매달 자동 반복
② Stickiness: 유저가 20~30개 레시피를 쌓아두면 취소 못 함 → 저처 방지
엑싯 잠재력 계산
- SaaS 앱 인수 배수: 연간 이익의 2~4배 (acquire.com · Flippa · Trust MRR 참조)
- 50% 마진 가정: 월 이익 $400K × 12 = 연 $4.8M 이익
- 최저 배수 2x → 최소 $9.6M 엑싯 가능

이 계산이 왜 이런 앱을 만들 가치가 있는가의 근거다. 매출 $800K/월도 대단하지만, $10M 엑싯 가능성이 인디해커의 진짜 목표점이 된다.

3. Cookpad 케이스 — 일본 특화로 월 $900K (3:00~3:50)

[[SECTION3_IMG]]

이미 시장에 다른 플레이어가 있지만 이것은 수요가 강하다는 시그널이다. 그리고 니치 특화가 오히려 더 큰 매출을 만들 수 있다는 케이스가 Cookpad.

Cookpad (일본 특화 레시피 앱)
- 시장: 일본만
- 매출: 월 $900,000 (원본 ResuMe보다 많음!)
- 원리: 문화별로 요리 · 재료 · 조리법에 대한 가치와 선호가 다름. 그걸 반영한 앱이 훨씬 개인화된 느낌.

이 케이스가 이 리포트에서 뽑아낼 가장 중요한 원칙 중 하나다. 니치화 = 매출 축소가 아니다. 오히려 특정 문화 · 특정 데모그래픽에 완전히 맞추면 범용 앱보다 더 많이 벌 수 있다.

4. 기술 스택 — Claude Design · Code · React Native · Expo Go (3:50~5:10)

[[SECTION4_IMG]]

Vibe Coded App 표준 스택 (2026)
- UI 디자인: Claude Design (버튼 · 색상 · 스크린)
- 백엔드 로직: Claude Code (기능 코드)
- 프레임워크: React Native — iOS + Android 단일 코드베이스
- 기기 테스트: Expo Go (App Store 배포 전 실기기 프리뷰)
- 대안: ChatGPT Codex desktop app도 동일하게 작동

Claude Code는 최소 $20 구독이 필요하다. 화자의 팁: Chat · Cowork · Code 세 탭 중 Code를 추천. 더 능력이 좋고 데스크톱 앱이 유저 친화적이라 버튼만 클릭하면 되고 터미널 작업 없음.

5. Claude Code 셋업과 프로젝트 폴더 구조 (5:10~6:30)

[[SECTION5_IMG]]

Claude Code 셋업 체크리스트
① Claude 데스크톱 앱 다운로드
② $20 구독 활성화
③ 프로젝트별 폴더 준비 (예: Recipe Snap)
④ Claude Code UI에서 그 폴더 선택 → 프로젝트 컨텍스트 설정
⑤ 영어 자연어 프롬프트로 작업 시작

폴더 조직화가 중요한 이유: 여러 앱을 동시에 짓게 되면 각 프로젝트의 컨텍스트가 분리돼야 Claude가 정확한 코드 파일을 수정한다.

6. UI 디자인 — Claude Design으로 스크린 생성 (6:30~15:00)

[[SECTION6_IMG]]

Claude Design을 사용해 앱의 UI를 생성한다. 이 도구는 디자인 시안을 만들어주고, 그것을 그대로 코드로 변환할 수 있게 해준다. 화자의 워크플로우:

  1. Claude Design에 앱 컨셉 프롬프트 → 스크린 여러 개 생성
  2. 홈 · 레시피 저장 · 라이브러리 · 쇼핑 리스트 · 설정 등 주요 스크린 5~7개
  3. 디자인이 마음에 들면 → Claude Code로 이동해 React Native 코드로 구현 지시
  4. 디자인 마이너 조정(색상 · 버튼)은 영어 프롬프트로 반복
UI 반복의 실전 팁
"녹색 진행 바로 바꿔줘" · "홈 카드 여백을 늘려줘" · "라이브러리 뷰에서 카테고리 태그를 컬러풀하게 해줘" — 자연어 지시만으로 UI 조정 가능.

7. 백엔드 로직 — Claude Code로 기능 연결 (15:00~22:00)

[[SECTION7_IMG]]

UI가 완성되면 Claude Code로 기능(functionality)을 붙인다.

이 앱의 핵심 기능들 (구현 순서)
① 레시피 저장 · 로컬 스토리지 (임시로 Mock 데이터)
② 라이브러리 · 카테고리별 필터
③ Cook Mode (조리 중 화면)
④ Shopping List 자동 생성
⑤ OpenAI API 연동 (이미지 인식 · 텍스트 추출)
⑥ YouTube 링크 파싱 (설명 · 이미지 · 원본 URL 자동 추출)
⑦ Make it Healthier AI 기능 (재료 대체 · 조리법 재작성)

각 기능은 Claude Code에 한 줄씩 프롬프트로 지시하면 자동 구현. 예: "레시피 저장 기능을 추가해줘. 로컬 스토리지에 저장하고 라이브러리 뷰에서 필터링 가능하게."

8. OpenAI API 연동 + Expo Go 실기기 테스트 (22:00~27:30)

[[SECTION8_IMG]]

API 키 셋업
① Claude Code에 ".env 파일을 만들어서 OpenAI API 키를 저장할 수 있게 해줘" 프롬프트
② 생성된 .env 파일에 API 키 붙여넣기
③ 백엔드 자동 재로드 → 키 로딩 확인
Expo Go 실기기 프리뷰
① 폰에 Expo Go 앱 다운로드 (App Store 무료)
② Claude Code에 "QR 코드를 생성해줘" 프롬프트
③ 폰 카메라로 QR 스캔 → 앱이 폰에 자동 로드
→ 개발자 없이도 실기기 테스트가 몇 초 만에 가능

9. 실제 기능 테스트 — 사진 스캔 · YouTube 링크 · Make Healthier (27:30~30:00)

[[SECTION9_IMG]]

화자가 완성된 앱을 실기기에서 테스트한다. 이 파트가 강의의 정점이다.

Test 1 — 물리적 레시피 사진 스캔
- 손으로 쓴 지저분한 메모 레시피 사진 촬영
- AI가 재료 · 조리법 자동 추출 → 깨끗한 레시피 카드 생성
- 저장 클릭 → 라이브러리에 즉시 추가

Test 2 — YouTube 링크 파싱
- Smash Burger 레시피 YouTube 링크 복사 → 앱에 붙여넣기
- Extract 클릭 → 재료 · 조리법 자동 추출
- 흥미로운 부분: YouTube 설명에서 certifiedangusbeef.com이라는 원본 URL을 감지 → 그 웹사이트에서 이미지까지 자동 가져옴
- 저장 → 완벽한 레시피 카드

Test 3 — Make it Healthier AI 기능
- 버거 레시피 열기 → Make it Healthier 버튼
- OpenAI API가 재료 대체 · 조리법 재작성 자동 생성
- 예: 소고기 → 칠면조 고기, 화이트 번 → 홀그레인 등

화자의 감상: "약 10~15분 만에 vibe coded 앱치고 정말 훌륭하다." 이후 프로덕션 배포를 위한 스택:

프로덕션 스택
- Database: Supabase (Claude Code가 연결 자동화)
- Payment/Subscription: RevenueCat (Apple 승인 · 인디해커 표준)
- Apple Developer Account: $99/년 (앱 무한 배포)

10. 마케팅과 App Store 체크리스트 — 진짜 승부처 (30:00~33:00)

[[SECTION10_IMG]]

화자의 핵심 명제: "앱 빌드보다 마케팅이 더 중요하다. 이제 누구나 vibe coding할 수 있으니 유저를 어떻게 얻는가가 승부처."

ResuMe의 실제 마케팅 — TikTok UGC
- 자체 TikTok 계정 운영
- UGC 크리에이터 고용
- 그들의 영상을 자체 계정에 리포스트
- 포맷: "I wish I knew this sooner" 스타일 — 문제 → 앱 솔루션 → 10초
3가지 UGC 전략 옵션
① 자체 계정 운영: 시간 많이 걸림, 꾸준함 필수, 하나 바이럴 뜨면 무료 유저 홍수
② 인간 UGC 크리에이터 고용: 고정 비용 · 영상 하나가 오래 유저 유입
③ AI UGC (Arcads · HeyGen): AI 아바타 여러 명 · TikTok 계정 여러 개 · 고볼륨 콘텐츠 → 바이럴 영상 찾아서 유료 광고로 스케일

화자의 마케팅 전략 요약: "콘텐츠를 많이 만들어라. 무엇이 통하는지 찾아라. 그리고 돈으로 스케일업."

App Store 배포 전 체크리스트 (18개 항목)
- 최근 vibe coded 앱들이 대량 거부되고 있음
- 이유: 보안 레이어 부족 · 신뢰성 부족
- 화자가 정리한 18개 항목을 Claude Code에 통째로 복사 → 앱이 다 커버하는지 자동 검증

핵심 요약 (Takeaways)

  1. 월 $800K 앱을 코드 한 줄 없이 클론할 수 있다. Claude Design + Code + React Native + Expo Go 조합만으로 30분 완성. 2026년은 앱 개발 진입 장벽이 사실상 0에 가까워진 시기.
  2. 이 시대의 승부처는 앱 빌드가 아니라 마케팅이다. 누구나 vibe coding 할 수 있으므로 유저를 어떻게 얻느냐가 결정적. 화자가 마케팅에 챕터 하나를 통째로 할당하는 이유.
  3. Stickiness + Recurring Revenue가 앱 밸류의 핵심. 유저가 데이터를 쌓아둘수록 이탈 못하고, 매달 자동 매출. 이 둘의 조합이 $10M+ 엑싯의 근거.
  4. SaaS 앱 인수 배수는 연간 이익의 2~4배. 50% 마진 앱이 월 $800K를 벌면 최소 $9.6M 엑싯이 실측 가능. acquire.com · Flippa · Trust MRR에서 실 거래 데이터 확인.
  5. 니치 특화가 오히려 매출을 늘린다. Cookpad(일본 전용)가 ResuMe(글로벌)보다 월 매출이 크다. 문화별 요리 · 재료 · 조리법 차이를 반영하면 개인화된 느낌.
  6. 표준 스택: Claude Design + Claude Code + React Native + Expo Go. UI는 Claude Design, 기능은 Claude Code, 프레임워크는 iOS/Android 통합 React Native, 실기기 테스트는 Expo Go (App Store 무료).
  7. Claude Code는 최소 $20 구독. Chat · Cowork · Code 중 Code 추천 (더 강력, 데스크톱 유저 프렌들리). 터미널 작업 없이 자연어 프롬프트만.
  8. API 연동은 .env 파일 프롬프트 하나로. ".env 파일 만들어서 OpenAI API 키 저장" 지시 → 파일 생성 → 키 붙여넣기 → 자동 재로드.
  9. Expo Go로 실기기 프리뷰가 몇 초 만에. QR 코드 스캔만으로 iPhone/Android에서 앱 실행. 개발자 없이도 실기기 UX 검증 가능.
  10. ResuMe의 3가지 AI 기능이 vibe coded로 30분 안에 완성: (a) 손 필기 레시피 사진 → 텍스트 추출, (b) YouTube 링크 → 재료/조리법 자동 파싱 + 원본 웹사이트 이미지 자동 스크래핑, (c) Make it Healthier — 재료 대체.
  11. 프로덕션 스택: Supabase(DB) + RevenueCat(구독) + Apple Developer $99/년. 인디해커 표준. Claude Code가 세 연동을 자동화.
  12. 마케팅 3가지 UGC 전략: 자체 TikTok 계정 (무료 · 시간 소요) · 인간 UGC 크리에이터 (고정비용 · 지속 유입) · AI UGC(Arcads · HeyGen — 고볼륨 → 바이럴 → 유료 광고 스케일).
  13. 포맷 표준: "I wish I knew this sooner" 10초 UGC. 문제 제시 → 앱 솔루션 → 클릭 유도. 이게 컨슈머 앱 UGC의 지배적 포맷.
  14. App Store 거부 방지 18개 체크리스트. Apple은 vibe coded 앱을 대량 거부 중. 이유는 보안 · 신뢰성. Claude Code에 체크리스트 통째로 붙여 자동 검증 가능.
