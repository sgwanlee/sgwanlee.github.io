Claude + ChatGPT로 90일 $60K를 만든 20살 크리에이터의 Faceless YouTube Shorts 매뉴얼

20살의 한 크리에이터가 얼굴 없이 운영하는 YouTube Shorts 채널로 지난 90일 동안 $60,000의 순이익을 냈다. 365일 기준으로는 27억 뷰, 총 이익 $236,000+. 이 리포트는 그가 그 결과를 만든 워크플로우 — Claude MCP + VidIQ로 경쟁자 분석 → Claude로 스크립트/클립 브레이크다운 → Viblo AI 편집기 → 실사·AI 클립 조합 → ChatGPT로 채널 브랜딩 → 트러스트 스코어 워밍업 → 발행까지를 그대로 정리한다. 그는 이 시점이 Shorts 진입에 가장 좋은 이유로 두 가지를 든다. ① 검색 트렌드가 5년 최저치일 만큼 진입자가 오히려 줄어들었고, ② YouTube의 Shorts RPM이 사상 최고치로 올라와 있다. 뷰가 4분의 1로 줄어도 매출은 같은 수준이 되는 실제 데이터가 이를 증명한다.

1. 90일 $60K의 실체 — 채널 데이터 공개

화자는 자신의 실제 YouTube Studio 대시보드를 공개하며 이 리포트의 신뢰도를 먼저 세운다.

공개 채널의 실제 수치
  • 지난 90일: 순이익 $60,000, 조회수 3.69억, 최고 하루 매출 약 $2,000
  • 지난 365일: 총 조회수 27억, 총 이익 $236,000+
  • 단일 Short 최고 조회 — 7,900만 뷰 → $3,900 (약 1년 전, RPM $0.09)
  • 가장 최근 Short — 3,700만 뷰 → $9,000 (RPM $0.38)
[##_Image|kage@shot_30|alignCenter|width="100%"|_##]

같은 채널, 같은 니치, 사실상 같은 유형의 영상인데도 최근 영상은 뷰당 4배의 수익을 낸다. 이 격차 자체가 이 리포트가 다루는 두 번째 명제 — "지금이 최고 시점"의 결정적 증거다.

2. 왜 지금이 Shorts 진입의 최고 시점인가

화자의 주장은 두 축이다.

지금이 최고 시점인 두 가지 이유
  1. 진입 경쟁이 최저 — Google Trends에서 "YouTube automation", "Faceless YouTube" 검색량이 지난 5년 최저치. 2023년 정점 이후 지속 하락. "Shorts는 이제 포화"라는 통념은 데이터로 반박된다.
  2. RPM 사상 최고치 — 이전에는 Shorts RPM이 $0.10~$0.15 수준으로 유튜브의 아픈 손가락이었지만, YouTube가 Shorts 수익 배분 정책을 계속 상향 조정하며 이제 사상 최고 구간에 진입.
[##_Image|kage@shot_60|alignCenter|width="100%"|_##]

3. RPM $0.09 → $0.38 — 같은 채널이 4배 벌기까지

화자는 이 상승을 자신의 채널 수치로 증명한다. 피크 시기 하루 3천만 뷰 → $2,000였는데, 현재는 하루 1천만 뷰 → 여전히 $2,000 근처다. 뷰가 1/4로 줄어도 매출은 그대로다. 개별 영상 사례는 더 극명하다.

  • 1년 전 영상 — 7,900만 뷰 → $3,900 (RPM $0.09)
  • 최근 1개월 영상 — 3,700만 뷰 → $9,000 (RPM $0.38, 4배 이상)
[##_Image|kage@shot_130|alignCenter|width="100%"|_##]

4. AI가 99% 자동화하는 워크플로우 개요

과거의 Shorts 제작은 시간 소모가 극단적이었다. 경쟁자 조사, 아이디어 발굴, 스크립트 작성, 클립 편집이 모두 수작업이었다. 이 리포트가 정리하는 워크플로우는 이 사이클을 Claude + ChatGPT + Viblo AI로 대체한다.

  • Claude MCP + VidIQ — 경쟁자 채널 자동 분석, 히트 영상 아이디어 추출, 스크립트 자동 생성
  • Viblo AI — 보이스오버, AI 클립 생성, 자막, 렌더링을 하나의 편집기에서 처리
  • ChatGPT — 채널 이름·로고·배너·설명·태그라인의 전체 브랜딩

5. Niche 선택 — Interesting Facts의 위력

화자가 2026년에 진입을 추천하는 니치는 Interesting Facts 계열이다. 20~30초 다큐멘터리 스타일의 짧은 클립으로, TikTok에서 가져온 실사 클립과 AI 생성 클립을 섞고 그 위에 보이스오버를 얹는 구조다.

Interesting Facts 니치의 실제 사례
  • 일반 채널 — 16.4만 구독자, 15일 전 영상이 440만 뷰
  • 동물 특화 채널 — 28.8만 구독자
  • 일본 문화 특화 채널 — 매 영상 수십만~수백만 뷰

핵심은 이 니치가 어떤 주제로도 각색 가능하다는 것이다. 동물, 국가, 역사, 기술 무엇이든 "재미있는 사실" 각도로 재구성할 수 있다.

6. Claude + VidIQ MCP로 경쟁자 채널 전체 분석

경쟁자 분석은 이 워크플로우에서 가장 큰 시간 절약 지점이다. 순서는 다음과 같다.

  1. YouTube Shorts 피드에서 유입되는 Interesting Facts 계열 채널을 구독·좋아요·댓글로 알고리즘에 신호를 준다 → 피드가 참고 채널로 채워짐
  2. VidIQ Chrome Extension을 설치한 뒤 Claude에서 커넥터로 VidIQ for Claude를 활성화
  3. Claude에서 커넥터 → Competitor Breakdown 선택 후 참고 채널의 채널 ID를 붙여넣기
  4. Claude가 채널의 바이럴 Short를 전수 분석 → 리포트 형태로 반환
  5. 후속 프롬프트: "이 채널의 Top 5 영상 주제, 참고 링크, 각 요약을 알려줘" → 사실상 바이럴이 검증된 5개 주제가 손에 들어옴

예시 리턴값에는 "왜 오토바이는 레이스 전에 낮춰지는가?", "카타나가 일부러 부러지도록 설계된 이유" 같은 즉시 재현 가능한 검증된 아이디어가 나열된다.

[##_Image|kage@shot_250|alignCenter|width="100%"|_##]

7. Claude 프롬프트 두 번으로 스크립트 + 클립 브레이크다운

아이디어가 정해지면 새 Claude 채팅에서 두 개의 프롬프트를 연달아 사용한다.

Claude 두 단계 프롬프트
  1. 스크립트 생성 — 앞서 뽑은 영상 요약을 붙여 넣고 "30초 분량의 바이럴 Shorts 스크립트를 써줘" 형태의 프롬프트로 요청. 정확히 30초 분량 스크립트가 생성됨.
  2. 클립 브레이크다운 — 두 번째 프롬프트로 위 스크립트를 4초 단위 세그먼트로 쪼개고, 각 세그먼트마다 시각적으로 어떤 종류의 클립이 재생되어야 하는지를 지정하게 함.

이 두 번의 프롬프트가 Shorts 제작에서 시간의 80%를 잡아먹던 부분을 정리해준다. 이후 편집자가 할 일은 클립 브레이크다운 시트를 따라가며 소재를 배치하는 것뿐이다.

8. Viblo AI 편집기 — 보이스오버·AI 클립·실사 클립 조합

편집은 Viblo AI 편집기 안에서 이뤄진다. 화자가 강조한 흐름은 다음과 같다.

  1. 편집기 상단 Full Editor 열기
  2. 하단 툴바 Speech에 Claude가 만든 전체 스크립트 붙여넣기 → 목소리 선택(Adam 기본) → Generate and Insert. 타임라인에 보이스오버 트랙이 자동 생성됨.
  3. 클립 브레이크다운의 첫 4초 클립 설명을 복사 → TikTok 검색에서 실사 클립이 나오면 그대로 사용, 안 나오면 Media → AI gen → Video generation에서 클립 설명 그대로 붙여 넣기, Cinematic + 720x1280 → 생성
  4. AI 클립은 오디오 mute 후 보이스오버와 함께 재생
  5. 다음 4초 세그먼트도 같은 절차 — 10개 내외 클립을 이렇게 채움
  6. AI 클립만 100%는 피하고 실사 클립을 반드시 섞어야 함. AI 티가 나면 도달률이 떨어짐
[##_Image|kage@shot_350|alignCenter|width="100%"|_##]

9. 자막 스타일과 렌더링

자막은 Viblo Subtitles → Generate Captions으로 한 번에 자동 생성된다. 기본 스타일은 밋밋하므로 Style → Random Color를 선택하고 폰트 사이즈를 실제 화면에서 커 보이는 정도까지 올린다. 필요하면 그림자·컬러 조정을 추가한다.

편집이 끝나면 Render로 영상을 다운로드한다. 여기까지가 한 개의 Shorts를 만드는 데 걸리는 시간이며, 익숙해지면 편당 20~30분 이내로 떨어진다.

10. 채널 셋업 — Aged 채널 vs 신규 채널 워밍업

영상을 만들 줄 알아도 채널 자체의 Trust Score가 낮으면 초반 도달이 크게 떨어진다. 화자의 룰은 명확하다.

기존 채널 vs 신규 채널 접근
  • Aged 채널이 있다면 재활용 — 몇 년 전 YouTube를 일반 시청 용도로 만들어둔 계정이 있다면 그것을 Faceless 채널로 전환. 트러스트 스코어가 이미 쌓여 있어 초기 도달이 훨씬 좋음.
  • 없다면 신규 생성 + 워밍업 — 새 채널을 만든 뒤 며칠 동안 실제 사용자처럼 Shorts 피드를 스크롤, 좋아요·댓글·구독을 남겨서 YouTube에게 "봇이 아니라 사람"이라는 신호를 보냄.

11. Feature Eligibility & Trust Score 관리

워밍업 2일차부터는 YouTube Studio → Settings → Channel → Feature Eligibility에 들어가 두 단계를 확인한다.

  1. Standard Features — 커뮤니티 가이드라인 위반이 없으면 기본 활성. 안 되어 있으면 채널을 새로 파는 편이 빠르다.
  2. Intermediate Features — 전화번호 인증 필요. 이 단계가 트러스트 스코어에 크게 기여한다.
  3. 3단계(Advanced)는 나중에 해도 됨.
[##_Image|kage@shot_550|alignCenter|width="100%"|_##]

12. ChatGPT로 채널 브랜딩을 5분에 끝내는 프롬프트 세트

브랜딩은 ChatGPT가 사실상 대신 만든다. 화자가 순서대로 사용하는 프롬프트는 다음과 같다.

4단계 브랜딩 프롬프트
  1. 채널 이름 — "Interesting Facts 채널의 짧고 한 단어짜리 이름을 여러 개 줘". 화자 예시는 Unfold. 오래 고민하지 말고 마음에 드는 것 하나 고를 것.
  2. 로고 — 채널 이름을 넣어 이미지 생성 프롬프트를 전달. 화자의 예시는 책이 열리며 금빛이 새어나오는 심플한 아이콘. 좋은 로고 예시(Slouch, Japan Chronicle)는 모두 단순한 형태다.
  3. 배너 — "로고와 같은 색상·디자인 스타일, 중앙에 짧은 문구 한 줄, 관련 아이콘". 화자의 예시는 "Subscribe for a cookie" + 쿠키 아이콘. 문구가 작으면 "텍스트 50% 크게" 후속 프롬프트로 조정.
  4. 채널 설명 — 정형화된 프롬프트로 태그라인 포함 채널 설명 자동 생성. 그대로 붙여넣기.

13. 발행 리듬과 지속성

채널이 세팅되면 이제 남은 것은 반복이다. 화자의 발행 룰은 명료하다.

  • 매일 1~2개의 Shorts 발행
  • 이 리듬을 최소 몇 주간 지속
  • 이 정도 지속성만 유지되면 주 수백만~수천만 뷰, 월 수천 달러의 수익 구조가 열릴 수 있다는 것이 그의 실증적 결론

14. 핵심 요약(Takeaways)

  1. Faceless YouTube Shorts는 지금 진입 시점이 가장 좋다. "YouTube automation" 검색량은 5년 최저, Shorts RPM은 사상 최고. 같은 채널, 같은 유형 영상이 뷰당 4배 매출을 낸다.
  2. 니치는 Interesting Facts 계열이 압도적. 20~30초 다큐 스타일, TikTok 실사 + AI 클립 조합, 어떤 주제든 각색 가능.
  3. Claude + VidIQ MCP가 경쟁자 분석과 아이디어 발굴의 80%를 대체한다. 채널 ID만 붙여넣으면 바이럴 검증된 5개 주제가 손에 들어온다.
  4. Claude 프롬프트 두 개로 30초 스크립트와 4초 단위 클립 브레이크다운을 자동 생성한다. 편집은 이 시트를 따라 채우기만 하면 된다.
  5. Viblo AI 편집기가 보이스오버·AI 클립·자막·렌더링을 한 곳에서 처리한다. AI 클립만 사용하면 도달률이 떨어지므로 실사 클립을 반드시 혼합하라.
